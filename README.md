# Burger on the Grill

Site institucional responsivo para uma hamburgueria de Cabrália Paulista/SP, pensado para o celular e para levar o cliente direto ao pedido pelo WhatsApp.

**Acesse online:** https://rayluansilva.github.io/Burguer-On-the-Grill/

## Seções

- **Início** com chamada principal e botão de pedido
- **Galeria** de fotos dos produtos
- **Cardápio** organizado por categorias
- **Sobre** a casa
- **Avaliações** de clientes
- **Localização e horário**, com mapa e contato

## Tecnologias

- HTML5 e CSS3 (variáveis CSS, layout responsivo)
- JavaScript puro
- Google Fonts (Ultra, Karla e Caveat)

## Como rodar localmente

O site é uma página única: basta abrir o `index.html` no navegador.
